# Data Preprocessing

Ham veriyi model eğitimine hazır hale getirmek için uygulanan temel ön işleme adımları.

## Kapsanan Konular

1. **Eksik veri işleme** — eksik değerlerin tespiti, gerekli durumlarda çıkarılması, uygun değerlerle (mean/median/mode vb.) doldurulması
2. **Aykırı değer tespiti** — IQR (Interquartile Range) yöntemiyle sayısal sütunlardaki outlier'ların tespiti
3. **Kategorik veri dönüşümü** — label encoding ve one-hot encoding ile kategorik değişkenlerin sayısal forma çevrilmesi
4. **Veri bölme** — train / test / validation set ayrımı
5. **Ölçeklendirme** — sayısal özelliklere standardization ve normalization uygulanması
